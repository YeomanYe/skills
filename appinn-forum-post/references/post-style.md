# 文案风格指南

## 三条铁律

1. **痛点切入**——读者先看到"什么痛"，再看到"什么解药"
2. **作者透明**——第一段就说"我开发的"，伪装第三方比硬广更糟
3. **链接精简**——只留商店 + 源码（最多再加官网），不要堆砌

## 标题格式

`「项目名」一句话定位：核心特性 1、核心特性 2、核心特性 3`

例：
- ✅ `「Ext Helper」浏览器扩展管理器：分组、按域名 / 时间自动开关、二分查找问题扩展`
- ✅ `「TabFloat」标签页悬浮窗：跨设备同步、全文搜索、快速切换`
- ❌ `推荐一个超好用的浏览器扩展！！！` —— 标题党
- ❌ `分享我的开源项目` —— 没信息量
- ❌ `Ext Helper` —— 单词太短，无法传达价值

## 正文模板

```markdown
推荐一个我开发的 <类型> **<项目名>**（<License> 开源），主要解决 <两到三个常见问题>：

1. <痛点 1：具体场景描述，不要抽象>
2. <痛点 2：另一个具体场景>

**核心功能：**

- **<功能 1>**：<一句话解释，带亮点>

![<功能 1 中文 alt>|690x<高度>](upload://<short_url_1>)

- **<功能 2>**：<一句话解释>

![<功能 2 中文 alt>|690x<高度>](upload://<short_url_2>)

- **<功能 3>**：<一句话解释>

![<功能 3 中文 alt>|690x<高度>](upload://<short_url_3>)

- **<功能 4>**：<一句话>

```

## 好示例（已发布，topic 84782）

> 推荐一个我开发的浏览器扩展管理器 **Ext Helper**（MIT 开源），主要解决两个常见问题：
>
> 1. 装了几十个扩展之后，某个网站突然挂了，不知道是哪个扩展导致的，只能一个个手动关
> 2. 部分扩展只在特定网站才需要（比如翻译插件只在外文站用），平时常驻浪费内存
>
> **核心功能：**
>
> - **Bisect 调试**：把当前启用的扩展二分禁用，刷新页面后标"好 / 坏"，几轮就能定位到具体哪个扩展出问题——`log₂(n)` 步而不是 `n` 步
> - **自动规则**：按域名（精确 / 包含 / 通配符 / 正则）+ 时间段，自动启用或禁用单个扩展或整个分组
> - **分组管理**：颜色区分、拖拽排序、整组一键开关
> - **撤销 / 重做**：每次操作都可回退
> - **跨浏览器**：Chrome / Edge / Firefox（基于 Plasmo）
>
> Chrome 应用商店：https://chromewebstore.google.com/detail/ext-helper/...
> 项目主页 & 源码（反馈欢迎）：https://github.com/...
>
> 还在迭代中，欢迎建议和拍砖。

为什么这个好：
- 痛点先于功能
- "我开发的"明示作者身份
- 功能列表配 `log₂(n)` 这种小亮点而不是空话
- 链接只两条
- 结尾不带"求 star / 求支持"

## 坏示例对照

### ❌ 自述调性
```
周末闲来无事，搓了个浏览器扩展管理器，欢迎大家试用！
功能很多，请看图。
[一堆截图]
```
问题：发现频道是"推荐"频道，自述像开发日记，发到 alpha 才合适。

### ❌ 假第三方
```
最近发现一个不错的扩展叫 Ext Helper...
（其实是作者本人）
```
问题：被识破后印象更差。直接说"我开发的"。

### ❌ 链接堆砌
```
GitHub: ...
Chrome 商店: ...
Edge 商店: ...
Firefox: ...
官网: ...
文档: ...
PayPal 赞助: ...
微信群: ...
```
问题：噪音 > 信号。读者只想点 1-2 个链接。商店 + 源码 即可。

### ❌ 求关注结尾
```
求 star、求转发、求支持！！！
```
问题：违反板块调性，社区会反感。改为"还在迭代中，欢迎建议和拍砖"。

## 调性差异：faxian vs alpha

| 维度 | faxian | alpha |
|---|---|---|
| 开头 | "推荐一个我开发的 X" | "我搓了个 / 周末做了个 X" 也可接受 |
| 自我评价 | 克制，靠功能说话 | 可适度自嘲、说"还很糙" |
| 求反馈 | "欢迎建议和拍砖" | "欢迎吐槽 / 求虐" 也行 |
| 长度 | 较完整（功能列表 + 截图） | 可以更短，重点说一两个亮点 |

## 图片嵌入语法

Discourse 标准 markdown：
```
![alt 文本|宽度x高度](upload://hash.ext)
```

- `宽度` 推荐 `690`（论坛主体最大宽度）
- `高度` 按上传响应里的 `width/height` 等比换算：`新高度 = 690 * 原高度 / 原宽度`
- alt 用中文，描述图的内容（不是文件名）

例：原图 1360×1264，写成 `![分组卡片视图|690x641](upload://abc.jpeg)`

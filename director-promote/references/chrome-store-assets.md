## Chrome Web Store 规范

### 必填素材

| 素材 | 尺寸 | 格式 | 备注 |
|---|---|---|---|
| 图标 | 128×128 | PNG | 商店列表用,**不是**扩展运行图标 |
| 小促销图 | 440×280 | PNG / JPG | 类目页缩略图,**必须包含产品真实截图**(见下方原则) |
| 截图 | 1280×800 或 640×400 | PNG / JPG | **1-5 张;至少 1 张必须是 1280×800** |
| short_description | ≤ 132 字符 | 纯文本 | 商店卡片副标题 |
| long_description | ≤ 16000 字符 | Markdown 子集 | 商店详情页正文 |

**截图硬规则**:
- 数量 **1-5 张**(至少 1,最多 5)
- **至少 1 张必须是 1280×800** —— 不能 5 张全用 640×400(小尺寸在详情页显得廉价)
- 多张截图之间**必须差异化**,见下方"同平台多图差异化"段

### 选填素材

| 素材 | 尺寸 | 用途 |
|---|---|---|
| 大促销图 | 920×680 | 类目页大卡片 |
| Marquee 促销图 | 1400×560 | 首页轮播位(需 Google 审核入选才显示) |
| 视频 | YouTube URL | 详情页展示 |

## 素材生成原则

### 促销图(promo tile)

调 `director-design mode=mockup,product_type=chrome-store-promo` 生成。要求:
- **必须包含产品真实截图** —— promo tile 不能做成纯文字海报(文字 + logo + 背景色),
  用户在类目页第一眼要看到产品长什么样;截图可裁切 / 加边框 / 叠标注,但产品画面必须在
- **主体明确**:产品名 + 一句话价值 + 产品截图视觉
- **不要小字**:小图 440×280 缩略后看不清的文字 = 没文字
- **品牌色统一**:用项目 design tokens 的主色
- **留白要够**:Google 审核会看视觉品质

### 截图

5 张策略(每张展示**不同的**功能 / 场景):
1. **总览图**(overview):展示主界面 + 核心功能位置
2. **核心功能 1**:具体场景下的功能演示
3. **核心功能 2**
4. **核心功能 3**
5. **差异化亮点**:跟竞品对比的差异点(可选,没有就 4 张)

每张截图**必须**:
- 真实使用截图(不是 mockup)
- 用了测试数据(无敏感信息,符合 9 维第 5 项)
- 必要时叠加文字标注(箭头 + 一句话说明)

### 同平台多图差异化(**硬规则**)

同一商店的多张截图 / 宣传图**必须真正差异化**,禁止做成"换皮"——同布局同场景只改配色或改 demo 数据。

**差异化标准:多张图在以下 3 个维度,至少 2 个维度互不相同**:

| 维度 | 含义 | 反例(雷同) |
|---|---|---|
| **展示功能** | 这张图突出哪个功能 / 界面 | 5 张都是同一个列表页 |
| **使用场景** | 用户在什么任务情境下 | 5 张都是"刚打开扩展"的空状态 |
| **取景视角** | 截全屏 / 局部放大 / 带浏览器框 / 标注引导 | 5 张都是同尺寸裸截全屏 |

**只换主色 / 只换 demo 数据 / 只换文案标注 ≠ 差异化** —— 这些是表层换皮,STOP。

派 `director-design` subagent 时,在 prompt 里要求**逐张声明差异点**,返回 JSON 的
`differentiation_note` 字段必须写清"第 N 张 vs 其他张在哪 2 个维度不同"。orchestrator
收图后核对:若任意两张在 3 维上少于 2 维不同 → 退回重做,不进交付目录。

## Edge Add-ons 规范

Edge 商店与 Chrome 的尺寸 / 必填素材不同,**完整规范见独立子模块 `references/platforms/edge.md`**。
关键差异速查:
- **300×300 logo tile**:Edge 商店特有,必须基于项目图标设计(Chrome 没有这一项)
- 截图:1366×768 或 1920×1080(比 Chrome 的 1280×800 大)
- short_description:≤ 200 字符(比 Chrome 宽)
- 同 Chrome 的"多图差异化"硬规则同样适用

出 Edge 素材时按 `platforms/edge.md` 的 spec 派 `director-design`,不要套用本文件的 Chrome 尺寸。

## Firefox Add-ons 规范(差异)

- 截图尺寸自由(常见 1280×800)
- summary:**≤ 250 字符**(类似 short_description)
- 描述支持完整 Markdown
- 必须提供"对其他扩展的兼容性说明"(若有冲突)

# Chrome Store Assets — 上架素材规范

> 由 `director-promote` 的 draft 模式生成,**交付**给 `flow-ext-publish` 执行上架。
> 本 skill **不执行**上架动作,只产素材。

## 交付目录结构

```
.agent/promote-handoff/<task-id>/store-assets/
├── chrome/
│   ├── promo-tile-440x280.png      # 小促销图(必填)
│   ├── promo-tile-920x680.png      # 大促销图(选填)
│   ├── promo-tile-1400x560.png     # marquee 推广位(选填)
│   ├── icon-128.png                 # 商店图标
│   ├── screenshots/
│   │   ├── 01-overview.png         # 1280×800 或 640×400
│   │   ├── 02-feature-A.png
│   │   ├── 03-feature-B.png
│   │   ├── 04-feature-C.png
│   │   └── 05-feature-D.png        # 最多 5 张
│   ├── description.md              # 含 short_description + long_description
│   └── meta.json                   # category / language / search_terms
├── edge/                            # Edge Add-ons(同 Chrome 截图 + 1366×768/1920×1080 各 1 张)
├── firefox/                         # Firefox Add-ons(描述较短)
└── README.md                        # 给 flow-ext-publish 看的清单
```

## Chrome Web Store 规范

### 必填素材

| 素材 | 尺寸 | 格式 | 备注 |
|---|---|---|---|
| 图标 | 128×128 | PNG | 商店列表用,**不是**扩展运行图标 |
| 小促销图 | 440×280 | PNG / JPG | 类目页缩略图 |
| 截图 | 1280×800 或 640×400 | PNG / JPG | 至少 1 张,最多 5 张 |
| short_description | ≤ 132 字符 | 纯文本 | 商店卡片副标题 |
| long_description | ≤ 16000 字符 | Markdown 子集 | 商店详情页正文 |

### 选填素材

| 素材 | 尺寸 | 用途 |
|---|---|---|
| 大促销图 | 920×680 | 类目页大卡片 |
| Marquee 促销图 | 1400×560 | 首页轮播位(需 Google 审核入选才显示) |
| 视频 | YouTube URL | 详情页展示 |

## 素材生成原则

### 促销图(promo tile)

调 `director-design mode=mockup,product_type=chrome-store-promo` 生成。要求:
- **主体明确**:产品名 + 一句话价值 + hero 视觉
- **不要小字**:小图 440×280 缩略后看不清的文字 = 没文字
- **品牌色统一**:用项目 design tokens 的主色
- **留白要够**:Google 审核会看视觉品质

### 截图

5 张策略:
1. **总览图**(overview):展示主界面 + 核心功能位置
2. **核心功能 1**:具体场景下的功能演示
3. **核心功能 2**
4. **核心功能 3**
5. **差异化亮点**:跟竞品对比的差异点(可选,没有就 4 张)

每张截图**必须**:
- 真实使用截图(不是 mockup)
- 用了测试数据(无敏感信息,符合 9 维第 5 项)
- 必要时叠加文字标注(箭头 + 一句话说明)

### Description

```markdown
# short_description(132 字符内)
解决 X 问题的 Y 工具——一句话说清价值。

# long_description(16000 字符内)
## 你遇到过这样的问题吗?
<痛点描述,1-2 段>

## 这个扩展能帮你
- ✅ 功能 1:一句话价值
- ✅ 功能 2
- ✅ 功能 3

## 适合谁用
- <用户画像 1>
- <用户画像 2>

## 隐私和数据
- 本地处理 / 不上传 / 开源
- 隐私政策:<URL>

## 反馈
- GitHub Issues:<URL>
- 邮箱:<email>
```

### meta.json

```json
{
  "category": "Developer Tools",     // 必须从 Chrome Store 类目列表选
  "language": "zh-CN",                // 主语言(描述语言)
  "search_terms": [                   // 5 个搜索关键词,各 ≤ 25 字符
    "Chrome extension manager",
    "browser tab",
    "developer tool",
    "productivity",
    "open source"
  ],
  "version": "1.2.0",                 // 从 manifest.json 读
  "homepage_url": "https://...",
  "support_url": "https://github.com/.../issues"
}
```

## Edge Add-ons 规范(差异)

- 截图尺寸:**1366×768 或 1920×1080**(比 Chrome 大)
- short_description:**≤ 200 字符**(比 Chrome 宽)
- 不需要 marquee 促销图
- 必须额外提供"扩展功能说明"(类似 Chrome long_description 但更结构化)

## Firefox Add-ons 规范(差异)

- 截图尺寸自由(常见 1280×800)
- summary:**≤ 250 字符**(类似 short_description)
- 描述支持完整 Markdown
- 必须提供"对其他扩展的兼容性说明"(若有冲突)

```
- director-design: 生成 5 张 chrome screenshots + 1 张 marquee(路径: ...)

```
